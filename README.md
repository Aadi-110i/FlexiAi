# (Orbit)

**Think without losing context.**

Orbit is an AI-powered infinite workspace. Unlike traditional linear chat interfaces, Orbit provides a persistent, spatial canvas where you can chat, research, code, and take notes—all simultaneously. 

**Problem:** Constant context switching between AI chats, code editors, search engines, and note-taking apps fragments your workflow and train of thought.  
**Solution:** A unified, infinite canvas where all your tools live side-by-side, maintaining context and flow.

### Features
* 🌌 **Infinite Canvas:** Drag, drop, and organize your workspace spatially.
* 💬 **AI Chat:** Context-aware AI assistants right where you need them.
* 🔍 **Research:** Integrated web search that feeds directly into your AI context.
* 💻 **Code Editor:** Built-in Monaco editor with syntax highlighting.
* 📝 **Notes & Drawing:** Quick markdown notes and diagrams.
